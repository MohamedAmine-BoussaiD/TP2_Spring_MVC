# Java Web Development Projects

A comprehensive repository containing tutorials and projects for Java web development, including Spring MVC and Servlet technologies.

## 📁 Repository Structure

```
.
├── mvc/                          # Spring MVC Projects
│   
│
├── servlet/                      # Servlet Projects 
│   ├── xml_version/              # Servlet with web.xml Configuration
│   └── annotation_version/       # Servlet with @WebServlet Annotation
│
│
└── README.md                     # This file
```

---

## 📚 Projects Overview

### 1. Spring MVC Projects (mvc/)
-  Spring MVC with Thymeleaf templates

### 2. Servlet Projects (servlet/)
- **xml_version/**: Traditional servlet configuration using `web.xml` deployment descriptor
- **annotation_version/**: Modern servlet configuration using Java annotations (`@WebServlet`)

## 🚀 Getting Started

### Prerequisites
- Java JDK 11 or higher
- Apache Tomcat 
- Maven 
- IDE (IntelliJ IDEA, Eclipse, or VS Code)

### Clone Repository
```bash
git clone https://github.com/MohamedAmine-BoussaiD/TP2_Spring_MVC.git
cd TP2_Spring_MVC
```
